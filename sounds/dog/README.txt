JESSI'S REAL VOICE (optional)
Jessi's barks, whines and sighs are made by a small voice model in film/js/dog.js, so she already speaks without any files.
If you have REAL recordings of a puppy (that you own or have the right to use), drop them in this folder - nothing to set up:
the start of the file name says which feeling it is:
   happy-1.mp3 (or bark / woof)   a playful bark          excited / yip     quick happy yips
   angry                          an indignant WOOF!      soft / ruff       a small, gentle woof
   sheepish   sleepy   yelp   whine   whimper   growl   yawn   sigh   pant   howl   snore   alert   awe
Several files with the same start are chosen at random. A recording replaces the synthesised sound for that feeling.
sounds/dog/list.js is rewritten automatically on every git commit (and by update-songs.bat); then commit + push.
