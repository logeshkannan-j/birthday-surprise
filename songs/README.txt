DROP SONGS HERE
Put any MP3 (or m4a / wav / ogg) of her favourite songs in this folder - that is all.
They play in name order when she turns the sound on, then loop. Nothing else is played.
  - The file name is the title shown on the page. Start it with a number to set the order: "01 - Apna Bana Le.mp3".
  - To remove a song, delete its file.
  - songs/list.js is rewritten automatically on every git commit (and by update-songs.bat), so a commit + push is enough.
Use songs you own or have the right to use.
